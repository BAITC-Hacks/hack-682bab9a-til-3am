# EKT frontend

Первый рабочий каркас: React + TypeScript + Vite. Локальный поиск по 40 товарам из корневых JSON, карточки, сообщения, ошибки и мобильный интерфейс. Это шаблонный поиск, не подключённая LLM. Исходные JSON должны оставаться в корне репозитория.

```bash
cd frontend
npm install
npm run dev
```

Проверка сборки: `npm run build`. Необходим Node.js 22.

По умолчанию работает без сервера. Для интеграции скопируйте `.env.example` в `.env.local`, задайте `VITE_API_MODE=live` и перезапустите Vite. `/api` проксируется на `http://127.0.0.1:8000`. Адаптер вызывает `POST /api/session`, затем `POST /api/chat` с cookie. Типы находятся в `src/types.ts`. Ключ NVIDIA хранится только на бэкенде.

Следующий этап: обработка proposal, серверное подтверждение и страница /cart. Они пока не реализованы. Live-режим пока не проверен с сервером. Внешние картинки могут быть недоступны — есть заглушка. Внешний шрифт имеет системный fallback. Валюта KZT — допущение прототипа; остатки отражают выгрузку.
