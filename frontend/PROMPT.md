# Один промпт для продолжения работы

```text
Ты отвечаешь за frontend EKT Assistant на хакатоне. Прочитай
HACKATHON_PLAN_RU.md, frontend/README.md и существующий frontend/src.
Работай только в frontend/**. Не перезаписывай изменения команды.
Стек уже настроен: React + TypeScript + Vite. Продолжай существующий
дизайн и код, не создавай приложение заново.

Цель: рабочий чат → карточки товаров → предложение добавить → явное
подтверждение → серверная демокорзина. API-контракт из общего плана;
если contracts/api.md уже существует, сверь расхождения с бэкендером.
Типы frontend/src/types.ts и адаптер src/api.ts — точки интеграции.
Сохрани локальный режим без LLM, явно обозначенный в интерфейсе.
Live-режим использует /api и cookie, сервер по localhost:8000.

Реализуй отображение proposal с товаром, складом, количеством и суммой.
Только явное подтверждение вызывает POST /api/cart/confirm с proposal_id.
Не меняй корзину по тексту модели. Защити кнопку от повторных кликов.
Сделай /cart через GET /api/cart, ссылку после успешного добавления,
ошибки истёкшего предложения и недостаточного/неизвестного остатка.
Корзина серверная; не создавай независимую корзину на клиенте.

Цены и наличие только из API/JSON. null — неизвестный остаток, не ноль.
Показывай конфликт 160/250 А для ID 515291, источник и режим данных.
Не выдумывай сертификаты, доставку и оплату. Не размещай ключ NVIDIA
в клиентском коде или VITE-переменных. Поддержи мобильный экран,
ожидание, ошибку с повтором и отсутствие картинки. Не добавляй
неработающие кнопки и не выдавай заглушки за реализованные функции.

Сначала проверь существующую сборку, затем реализуй следующий рабочий
шаг. После изменений запусти npm run build, проверь основные сценарии.
Сообщи изменённые файлы, результат проверки и ограничения.
Нужно 5 содержательных коммитов за 4 часа: стартовый и по одному
в конце каждого часа. Не делай пустые коммиты и не добавляй чужие файлы.
Публикуй ветку только по разрешению участника.
```
